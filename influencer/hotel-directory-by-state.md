# Luxury Hotel Directory — All 50 States + DC

A geographic companion to **`hotel-outreach-list.md`** (which has the strategy, email template, PR agencies, and corporate-brand contacts). This file is the **where** — luxury/upscale hotels organized by **state → beautiful spot** (national parks, scenic areas, major cities), with the best contact to pitch for an influencer hosted stay.

**Confidence:** ✅ verified on an official page/release · 🟡 handled by a named PR agency (a reliable route) · 🔵 general/inferred — a form, main line, or email-format guess; **confirm before sending.**
Many hotel press pages block bots, so ✅ often means "captured from the official page via search." **Open the source and eyeball any address before you send. Never blast a 🔵 inferred one.** Roles change — re-verify.

> **Fast path anywhere:** for any Four Seasons, use the **"Envoy by Four Seasons" influencer form**; for any Waldorf Astoria/Conrad, use **Hilton's influencer-inquiry form** (both in the playbook file). For agency-repped hotels, pitch the agency — one relationship unlocks their whole portfolio.
